Ejemplo de código en Java

public class SaludoDAM {
    public static void main(String[] args) {
        String modulo = "Lenguajes de Marcas";
        int curso = 1;
        System.out.println("Hola desde " + curso + ".º DAM - " + modulo);
    }
}

Para ejecutar este programa, abre la terminal pulsando Ctrl + Alt + T, compila el archivo escribiendo javac SaludoDAM.java seguido de Enter, y después ejecútalo con java SaludoDAM + Enter. La consola mostrará la siguiente salida: Hola desde 1.º DAM - Lenguajes de Marcas.
